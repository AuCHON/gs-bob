# 球球大乱斗 · 双人同屏对战

两名玩家在同一台电脑上实时对战的网页小游戏:控制自己的球球撞击对手,把对方撞下平台!
先得**设定分数**或常规 **2:30** 计时结束分高者获胜;平分进入"突然死亡"——平台在 15 秒内收缩殆尽、下一分定胜负。
获胜分数开局前在菜单设置(**3~16** 分,默认 3):默认 3 分制整局在 **3 分钟以内**,更高分数设定在极端多分对局下至多约 **3 分半**。

## 启动说明

纯静态页面,零依赖,无需构建。以下三种方式任选其一:

### 方式一:HTTP 服务启动(推荐,符合大赛试玩地址要求)

1. 打开命令行(Windows 下可用 `cmd` 或 PowerShell);
2. 切换到本项目目录(即 `index.html` 所在目录):
   ```bash
   cd /path/to/本项目目录
   ```
3. 启动服务(端口 **9201**):
   ```bash
   python -m http.server 9201
   ```
4. 在浏览器中打开试玩地址:
   - 本机:<http://127.0.0.1:9201>
   - 同内网设备:`http://<本机内网 IP>:9201`(内网 IP 可用 `ipconfig` / `ifconfig` 查看)
5. 停止服务:在命令行按 `Ctrl + C`。

> 提示:需已安装 Python 3;若内网设备无法访问,多为防火墙拦截,可放行 TCP 9201 端口后重试。

### 方式二:无 Python 时的替代命令

```bash
npx serve . -l 9201        # 需已安装 Node.js
```

### 方式三:直接打开

双击 `index.html` 在浏览器中即可离线游玩(单人本地体验,无需任何服务)。

推荐使用 Chrome / Edge 等现代浏览器。

## 操作说明

| 动作 | 玩家 1(红色) | 玩家 2(蓝色) |
|------|------------|------------|
| 左右移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 下砸(空中按下,落地产生冲击波震飞对手) | S | ↓ |
| 冲刺(冷却 2.6 秒,球体亮起白色光环即就绪) | 空格 | 回车 |
| 暂停 / 继续 | P | P |
| 重新开始(任意时刻) | R | R |

**触屏设备**:对局开始后,画面左下/右下出现虚拟按键(玩家1 W/A/S/D+冲刺条,玩家2 方向键+回车条),点按即可操控,按下会点亮;竖屏会出现"横屏体验更佳"提示(可关闭)。暂停后点击画面即可继续。P 暂停 / R 重新开始为键盘专属操作。

开局前可在菜单用 − / + 按钮设置获胜分数(3~16,默认 3);结算界面可"返回菜单"重新调整。

## 道具(随机刷新在平台上)

图标为画面内自绘矢量样式,括号内为图标形状:

- **加速**(闪电):5 秒内移速提升
- **变大**(外扩箭头):6 秒内体积变大、更重、撞击更有力(但更笨重)
- **冰冻**(雪花):冻住对手 2.5 秒
- **冲刺充能**(八向星芒):立刻刷新冲刺并获得短暂爆发

## 玩法技巧

- 高速撞击时的冲量更大,侧面偷袭比正面顶牛更有效。
- 空中下砸落在对手附近可将其震飞。
- 冲刺既是进攻手段,也是回平台的保命技能。

