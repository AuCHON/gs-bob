## 〇、增量基准(降级自审产出)

1. **问题量化**:现触屏档按键 44~46px,游戏高频盲操偏小;且横屏手机(视口宽>760px)落入桌面档,按键未随舞台放大。
2. **分档方案**(第 1 轮修正版;纯 CSS,`any-pointer: coarse` 设备有触控能力即生效,纯鼠标桌面不变 46/44):
   - **基础档**(无容器查询依赖,任何浏览器):3 列 44px,不劣于改前
   - **自适应档**(`@supports (width: 1cqw)`):竖屏 3 列 `clamp(44px, 13cqw, 52px)`/冲刺 `clamp(44px, 12cqw, 48px)`;横屏**扁宽 4+1**(WASD 一排+通栏冲刺)`clamp(44px, 10.5cqw, 54px)`/冲刺 `clamp(44px, 9cqw, 46px)`——44px 触控下限是硬不变量,任何缩放不破
3. **自适应**:`#stage { container-type: inline-size }`;回退链=基础档(3×44,布局不破相)。
4. **验收口径**(第 1 轮修正):footprint(栈高含 6px 底边距)横屏 ≤112px;**语义线不遮**——球体(58.75% 线)与平台沿口(62.5% 线)不被遮挡,平台板身下部允许半透明交叠;双簇总宽含边距 ≤ 舞台宽,横屏 ≥480px 舞台中心距 ≥25px(竖屏 ≤320 档 ~11px 记为已知情例外);桌面档数值不变。
5. **提示卡**:自适应档 `bottom: min(186px, calc(66.67cqw - 56px))`——高于竖屏栈高且不被舞台顶边裁切;基础档沿用 168。
6. **测试**:CSS 契约断言含块序(>窄屏块)/@supports 分层/clamp 数值/grid-area 重排/回落基础档。
