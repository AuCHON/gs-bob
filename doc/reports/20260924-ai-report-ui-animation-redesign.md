## 〇、修正后需求基准（阶段 A 产出，开发与实现核对均以此为准）

1. **目标**：对"球球大乱斗"进行 UI 与动画重设计，提升美观度与游戏体验；不改玩法。
2. **风格**：霓虹街机（NEON ARCADE）——深空蓝黑底、霓虹发光、撞击火花、冲刺残影。
   用户在三个方向（霓虹街机/糖果乐园/极简电竞）被询问后表示无偏好，采用推荐项（对话留痕）。
3. **改动深度**：保留信息架构（右侧栏 + 顶部 HUD + 双 overlay + canvas 层），仅重设计视觉与动效；
   允许在现有结构内做增强性追加（如 HUD 内比分点阵），不删既有元素、不改交互习惯。
4. **冻结项**（重设计不得触碰）：物理/判定常量（GRAVITY、JUMP_V、SLAM_V、DASH_V、DASH_CD、
   MAX_VX、碰撞冲量系数等）、场景节拍常量（GAME_TIME=150、countT=3.2、bannerT=1.4）、
   键位映射、计分与胜负规则、道具效果数值与刷新节奏（propTimer 5+rand3、同屏 ≤3、life 9）。
5. **允许的表现层手感**：hit-stop 顿帧 ≤80ms、球体 squash & stretch 形变、冲刺/高速拖尾残影、
   震屏强化、冲击波/闪光/浮字——均为纯表现叠加，不写入任何游戏状态判定。
6. **资产约束**：禁止一切外部网络资源（README 承诺双击离线可玩）；不新增二进制资产文件，
   视觉全部以 CSS/canvas 矢量实现；新增源码文件须同步 README"文件结构"一节。
7. **道具图标统一**：统一为自绘矢量图标（canvas 矢量绘制 + 侧栏内联 SVG 同构），
   消除现有 ⭕（game.js PROP_TYPES）与 🔴（README/index.html）矛盾；删除死字段 `label`。
8. **兼容/性能基线**：Chrome/Edge 最近两个大版本；960×640 稳定 60fps；同屏粒子上限 ≤300；
   避免逐帧 shadowBlur/全屏渐变重建（预渲染离屏层）。
9. **无障碍**：`prefers-reduced-motion` 降级（减弱震屏/粒子/闪烁）；P1/P2 除颜色外叠加形状线索。
10. **测试基线**：新增 `package.json` + `test/smoke.js`（node --check 语法门 + mock DOM 全流程冒烟：
    菜单→开局→计时→突然死亡→结算 不抛错且状态流转正确）；PASS 前 `npm test` 连续 3 次全绿
    （用户裁定，替代 CLAUDE.md 原文所指的不存在设施）。
11. **音效**：本次不动 sfx（需求未提，🟡9 默认）。
12. **窄屏**：保留现有 760px 断点行为（侧栏移至下方）。
13. **范围补正**（🟡13）：canvas 内"已暂停"覆盖层属 UI，纳入重设计范围。
14. **文档同步义务**：README 的道具图标描述、文件结构、（如涉及）操作说明须与实现一致。
